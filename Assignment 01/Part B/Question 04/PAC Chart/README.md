## Question 4 — Online Shopping Bill Calculator

### PAC Chart

| Section | Details |
|---|---|
| **Given Data** | Quantity, price per item, discount percentage, and tax percentage. |
| **Required Result** | Calculate and display the subtotal, discounted amount, tax, and final bill. |
| **Processing Required** | Calculate subtotal using quantity × price. Subtract the discount from the subtotal. Calculate tax on the discounted amount and add it to get the final bill. Validate the input values before performing calculations. |
| **Solution Alternatives** | Use separate variables for each calculation. Use `if` statements to validate the inputs and terminate the program if invalid data is entered. |
